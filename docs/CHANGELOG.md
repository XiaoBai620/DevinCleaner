# 更新记录

## 1.0.0

- 首个 C# 版本，结构与 CodexCleaner 一致：WinForms 界面 + `Engine/` 清理引擎 + xunit 合成数据测试。
- 读取 `%APPDATA%\devin\cli\sessions.db`，列出会话标题、工作目录、最后活动时间、消息数与大小，支持搜索和筛选。
- 删除前生成 15 分钟有效的预览；执行时复查数据库结构指纹和每个会话的消息计数，预览后有变化就拒绝。
- 正在运行的会话按 `session_locks` 文件是否被占用来识别（不依赖可能被复用的 PID），Devin 开着时也能清理其他会话；执行期间独占锁文件，防止会话被同时打开。
- 删除前把所选会话的全部行备份到 `%LOCALAPPDATA%\DevinCleaner\Backups`，校验行数后才删除；可在「备份与恢复」中恢复。
- 可选清理孤立锁文件、压缩数据库（VACUUM）。
- 启动后检查 GitHub 正式版本，点击「前往更新」才打开发布页。
