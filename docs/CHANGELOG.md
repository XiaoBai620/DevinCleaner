# 更新记录

## 1.3.0

- 支持内置更新：启动后后台检查正式版本，展示简要更新内容；点击「查看并更新」可阅读、复制完整说明，下载新版并重新启动，保留「手动下载」入口。
- 下载显示进度、百分比和大小，支持取消后在原窗口重试；过滤上一轮延迟进度，失败时可查看、复制完整错误详情。清理、恢复等操作期间禁用安装入口。
- 只接受本仓库对应版本的更新附件，校验文件大小、SHA-256、Windows 64 位程序格式、产品名称和版本；校验失败不替换程序。
- 独立更新助手等待原程序退出后替换 exe，保留旧文件直到新版窗口确认启动；替换或启动失败时尝试回滚，无法确认安全恢复时保留材料。不保证断电后的自动恢复。
- 更新只处理程序与更新暂存文件，不修改 Devin 会话、配置或清理备份。1.2.1 及更早版本需从发布页手动替换一次 exe，之后可使用内置更新。

## 1.2.1

- 「备份与恢复」新增「全选 / 取消全选」，只勾选可恢复的会话（已存在于当前数据库的会话不勾选）。
- README 说明发布的 `DevinCleaner.exe` 可单独运行，无需附带 dll 或数据库文件。

## 1.2.0

- 新图标与界面：白底黑色六边形图标（`scripts/make_icon.py` 生成并嵌入 exe）；配色、圆角、按钮和状态标签改为 Devin 桌面版风格。
- 对话窗口照 Devin 聊天区重做：内容居中限宽，你的消息为右侧灰色气泡，Devin 回复直接排版；每次工具调用单独一行，显示命令 / 文件 / 搜索词 / 网址，点击展开参数和结果；参数按「键: 值」原样显示，不再是一行转义 JSON。
- 对话不再截断：去掉单条 6000 字的显示上限（超过 2 万字先显示前 2 万字，可原位展开）；工具参数上限从 4000、结果上限从 2 万字提高到 20 万字。实测真实库中最长的工具结果约 2.2 万字、单条消息约 35 万字。
- 聊天中的截图（`images`，用户消息和工具结果）直接显示，点击看大图，右键复制图片。
- 清理时按阶段显示进度和耗时（锁定 → 备份 → 校验 → 删除 → 刷新），不再长时间只显示「正在处理」。在 1 GB 库副本上删除 18 个会话（436 MB）约 8 秒，界面最大延迟 119 ms。
- 「备份与恢复」的读取、恢复、删除改到后台线程；此前恢复几百 MB 时界面线程会阻塞 5 秒以上，被 Windows 标记为「未响应」。

## 1.1.0

- 启动更快：统计消息大小改用 `octet_length`，不再把全部消息读入内存；1.2 GB 的库读取列表从 2～17 秒降到约 0.4 秒。
- 对话窗口支持拖动选择任意文字，Ctrl+C 复制、Ctrl+A 全选、双击选中整条，拖到边缘自动滚动。
- Devin 回复按 Markdown 显示：标题、粗体、行内代码、代码块、列表、引用和分隔线；表格和链接保持原文。
- 孤立锁数量显示在勾选框标题上，说明文字改为单行。

## 1.0.0

- 首个 C# 版本，结构与 CodexCleaner 一致：WinForms 界面 + `Engine/` 清理引擎 + xunit 合成数据测试。
- 读取 `%APPDATA%\devin\cli\sessions.db`，列出会话标题、工作目录、最后活动时间、消息数与大小，支持搜索和筛选。
- 删除前生成 15 分钟有效的预览；执行时复查数据库结构指纹和每个会话的消息计数，预览后有变化就拒绝。
- 正在运行的会话按 `session_locks` 文件是否被占用来识别（不依赖可能被复用的 PID），Devin 开着时也能清理其他会话；执行期间独占锁文件，防止会话被同时打开。
- 删除前把所选会话的全部行备份到 `%LOCALAPPDATA%\DevinCleaner\Backups`，校验行数后才删除；可在「备份与恢复」中恢复。
- 可选清理孤立锁文件，并附简短说明。
- 新增「查看对话」聊天窗口（只读，按 `main_chain_id` 显示主线）：工具调用折叠、思考过程/系统消息可选显示、双击全文、右键复制。
- 移除「压缩数据库」：删除会话后可回收的空闲页通常很少，VACUUM 却要重写整个库并需要同等临时空间。
- 启动后检查 GitHub 正式版本，点击「前往更新」才打开发布页。
